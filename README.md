# Угадай кто? — Telegram-бот для игры вдвоём

## 1. Создай бота
В @BotFather: `/newbot` → получишь **токен** и **username** бота.

## 2. Задеплой (нужен Node 18+)
Любой хостинг с Node и WebSocket: Render, Railway, Fly.io, свой VPS.
Команды: `npm install` и `npm start`. Нужен HTTPS-адрес.

Переменные окружения:
- `BOT_TOKEN` — токен от BotFather
- `WEBAPP_URL` — https-адрес твоего деплоя
- `BOT_USERNAME` — username бота без @ (необязательно)
- `APP_SHORTNAME` — короткое имя Mini App (необязательно, см. п. 3)

## 3. Ссылки-приглашения (необязательно)
В @BotFather: `/newapp` → выбери бота → укажи WEBAPP_URL и short name.
Тогда приглашение открывает игру прямо в Telegram по ссылке t.me/бот/short_name?startapp=КОД.
Без этого приглашение ведёт на обычную веб-страницу с кодом комнаты — тоже работает.

## 4. Играть
Напиши боту /start → «Играть» → «Создать комнату» → «Пригласить друга».

Фото персонажей подгружаются из Википедии; если не нашлись — показываются эмодзи.
